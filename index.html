      About this library

      A public, ToS-safe study library with a searchable dark/light site. Large PDFs stay on Release v1.0 so the git repo stays pushable.

      Browse on the website

      Use search, collapsible folders and topic pages. Switch dark/light from the header — the choice is saved in this browser.

      In-repo vs Release

      Smaller files open from topic folders in this repository. Files of about 8 MB and up download from the Large Files table (GitHub Release v1.0).

      What is left out

      Purchased/copyrighted course videos, redistributable-restricted commercial books, installers, and security-tool how-tos are not included. Digital Skills is a catalog of lesson names only.
